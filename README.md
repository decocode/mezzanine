# Mezzanine

Mezzanine is an accessible design system by [DecoCode Ltd](https://decocode.fly.dev),
built with React and [React Aria Components](https://react-aria.adobe.com/).

React Aria handles keyboard, focus, touch and screen reader behaviour. Mezzanine
adds the appearance: components, typography, spacing, colour and motion, all
driven by design tokens so each product can have its own theme. It comes with
three themes: Light, Dark and Wireframe.

**See it:** [mezzanine.fly.dev](https://mezzanine.fly.dev) shows every component,
with live examples and guidance.

## What's here

- `src/` – the component library
- `site/` – the documentation site, including the Lab, a sandbox for experiments
- `src/docs/` – guides to the tokens, typography and components

[MAP.md](MAP.md) lists every file and what it does.

## Running it locally

You need [Node.js](https://nodejs.org/) 24.

```bash
npm install
```

```bash
npm run dev
```
